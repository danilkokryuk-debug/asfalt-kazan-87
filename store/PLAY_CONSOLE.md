# Как выложить «Асфальт» в Google Play — по шагам

Готовые файлы:
- `android-app/out/app-release.aab` — его загружаешь в Play Console;
- `android-app/out/app-release.apk` — можно поставить на свой Android-телефон и проверить;
- картинки, тексты, ролик — в папке `store/` (тексты — `store/LISTING.md`).

**Ключ подписи** — `android-app/signing/upload.jks` и пароль в `android-app/signing/keystore.properties`.
Сохрани эту папку в надёжное место (флешка, облако). Без неё обновления в Play не загрузить.
В git она не попадает специально.

## 1. Аккаунт разработчика (делаешь сам)
1. play.google.com/console → создать аккаунт разработчика, «Личный».
2. Разовый взнос 25 $ и проверка личности (паспорт) — несколько дней.
3. Для приложений с покупками: «Настройка платежей» (Payments profile) — нужен, чтобы получать деньги.

## 2. Приложение
1. «Создать приложение» → название «Асфальт. Казань-87», язык русский, «Игра», «Бесплатное».
2. Главная страница приложения → раздел «Настройка»: пройти все пункты:
   - Политика конфиденциальности: `https://danilkokryuk-debug.github.io/asfalt-kazan-87/privacy.html`
   - Доступ к приложению: «Всё доступно без входа».
   - Реклама: **«Да, содержит рекламу»**.
   - Возрастной рейтинг: анкета IARC — ответы в `store/LISTING.md`.
   - Целевая аудитория: 16–17 и 18+.
   - Безопасность данных — ответы в `store/LISTING.md`.
   - Удаление аккаунта: ссылка `…/privacy.html#delete`.
3. «Основная страница в Google Play»: тексты, иконка `store/icon_512.png`, баннер `store/feature_graphic.png`,
   скриншоты `store/shots/*.png`, видео — ссылка на YouTube (залей `store/promo/asfalt_promo.mp4`).

## 3. Первая загрузка
1. «Тестирование → Внутреннее тестирование» → «Создать выпуск» → загрузить `app-release.aab`.
2. Подпись приложений Google Play — согласиться (Google хранит главный ключ, ты — ключ загрузки).
3. Добавь себя в тестировщики по почте, открой ссылку на телефоне и поставь игру.

## 4. Товары (чеки)
После первой загрузки: «Монетизация → Товары → Внутриигровые товары» → создать три товара
с **точно такими** идентификаторами:

| ID | Что | Цена (предложение) |
|---|---|---|
| `cheki_100` | 100 чеков | 0,99 $ |
| `cheki_350` | 350 чеков | 2,49 $ |
| `cheki_1000` | 1000 чеков | 5,99 $ |

Цену задаёшь один раз — Google сам пересчитает её в гривны, тенге, лари и т. д. и покажет игроку
в его валюте (игра берёт цену прямо из Google Play). Товары сделать «Активными».

## 5. Реклама (AdMob)
1. admob.google.com → войти тем же Google-аккаунтом → «Приложения → Добавить» → Android, найти «Асфальт».
2. Создать рекламный блок **«С вознаграждением»** (Rewarded).
3. Пришли мне два id: **id приложения** (`ca-app-pub-…~…`) и **id блока** (`ca-app-pub-…/…`).
   Я впишу их вместо тестовых, пересоберу и дам новый `.aab`.
   Пока стоят тестовые id Google — показывается пробная реклама, денег она не приносит.
4. В AdMob: «Конфиденциальность и сообщения» → создать сообщение GDPR (согласие для Европы).

## 6. Выпуск
Когда всё проверено на внутреннем тесте: «Рабочая версия → Создать выпуск» → тот же `.aab` → отправить на проверку.
Первая проверка Google — от нескольких дней до пары недель.

## Важно
- Покупки и реклама Google **не работают для игроков из России** (их там отключил Google). Для них — только бесплатное.
- Новая версия игры для Play: увеличь `versionCode` в `android-app/android/app/build.gradle` (1 → 2 → 3…)
  и запусти `powershell -ExecutionPolicy Bypass -File android-app\build.ps1 release`.
